## Task A:  Portfolio Analysis
Portfolio1-Andrew Ng's Engineering portfolio

Navigability: The portfolio is organized through repositories, making individual projects easy to find. A reader familiar with GitHub can identify specific projects by their repository titles and descriptions in 60 seconds or less.

Reproducibility: Reproducibility varies between the repositories. Projects with detailed README files provide info on the purpose and implementation but some projects would require additional information before another engineer could reproduce the work without asking questions.

Evidence of reasoning: the portfolio provides evidence of the technical work and project outcomes, but the amount of info explaining design decision varies by project. some repositories show implementation details without fully documenting a particular method or design that was selected.

Professional Tone: The technical descriptions and project documentation use engineering terminology and communicate project info in an appropriate format for the audience. however, the documentation isn't consistent for each repository

Portfolio2- MIT Mechanical Engineering Student portfolios

Navigability: The MIT Mechanical engineering website organizes info on programs, people, and projects. A reader can locate specific engineering work but using the site's categories, although finding an individual student's project requires more searching

Reproducibility: The site has descriptions of engineering projects and research, but the documentation is intended to communicate results rather than provide dimensions, materials, and procedures may not always be available.

Evidence of Reasoning: Project descriptions show context about engineering problems and approaches, but they do not document the complete decision-making process. A stronger engineering portfolio would include design requirements, calculation, and justification for final testing.

Professional Tone: The language is good for an academic and engineering audience. The technical descriptions provided focus on engineering objectives and results making the material more appropriate for an employer reviewing experience.
## Task B:  Product Analysis


## Decide

Homepage Identity: The homepage identifies this site as an engineering portfolio and explains what type of engineering work the reader will find and the documentation standard used through the portfolio. This info is for an employer, instructor, or engineering colleague who may be reviewing the portfolio for the first time and needs to know its purpose without searching through individual assignments. The homepage prioritizes the portfolio's contents and engineering documentation rather than personal background.

One Intentional Customization: I will customize the section labels in the portfolio navigation so that they can describe the purpsoe of each section using concise engineering terminology. This change satisfies the requirement for navigability because the reader should be able to identify where different types of work are located without looking a multiple page. The template labels provide the require structure.

Documentation Standard: For each assignment entry, I will document the engineering problem, methods, and calculation so that another engineering student or colleague and can understand and evaluate the work without additional explanation.
